# 选题判定标准（从候选到"能写"的决策树）

> 建立：2026-10-13
> 来源：从 52 篇历史稿＋5 条记坑＋被否掉的 60 余条选题中反向提炼
> **★这是本项目的核心资产★**——排版能抄、字数能数，**"哪条值得写"才是这套东西真正的know-how**
> 配套：`工作手册（私有，未随包发布）`（流程与操作细节）、`选题判断（私有，未随包发布）`（同一套口径的现行版）、分支 skill `rmt-yq`（单篇报送件）／`rmt-rb`（日报）——写作体例与排版

## 〇、一句话总纲

> **值得写的选题＝议题真实存在 × 时效在窗口内 × 议论是真人且够量 × 议题性质匹配体裁 × 事实有源头 × 落点有接口且领导能下令。**
>
> **六项全过 → 写；缺一项但可补 → 待观察；缺硬项 → pass。**
>
> **★2026-10-13 修订：闸门 1 补一条判据（1-②），并新增闸门 7（特别处置）。修订依据见《docs/02-验证-反向验证.md》——用 52 篇历史稿反向检验，原版 16 个历史问题只拦得住 11 个（69%），补两条后 16 个全拦住（100%）。★**

## 一、决策树（七个闸门，按顺序过）

顺序不能乱——**前面的闸门成本低，后面的成本高**。先在便宜的地方毙掉，别把时间花在写稿上才发现不该写。

```
候选选题（来自榜单/辅助源）
  │
  ├─【闸门1】议题真实吗？★两条判据，缺一不可★
  │     ├─ 话题页/搜索结果里全是机构号（政务号/公安号/媒体号）→ ✗ 假热
  │     ├─ 同一段文案被大量账号复制（矩阵号）→ ✗ 假热
  │     ├─ 景区/商家借政策话题做营销 → ✗ 假热
  │     ├─ 只有榜单词条、无独立数据、议论是博主解读 → ⚠ 降级待判（不直接毙）
  │     ├─ ① 有真人原创帖、有观点分歧 → ✓ 过第一条
  │     └─ ② **我能引到真人原话吗？（成稿来源表里至少一条"网民个人账号原创帖"）**
  │           └─ 引不到、论据只能靠媒体转述或官媒报道 → ✗ **主体不合格**
  │           └─ **★1-② 是 2026-10-13 补的★**：原判据只查"舆论场里有没有真人"（现场），
  │              漏了"我实际引用的论据是不是来自真人"（证据链）。
  │              某低价商品仅退款争议、某上市公司食品安全处罚、校园电动车三条就是这样漏过去的——话题页有真人，但稿子里的论据全来自媒体转述。
  │
  ├─【闸门2】时效在窗口内吗？（★两个方向都要查★）
  │     ├─ 事情是旧的？（查权威源**原始发布日**）→ ✗ 旧闻新炒
  │     ├─ 议论是旧的？（查话题页**最新帖日期**）→ ✗ 时效否决
  │     │     └─ 判据：最新帖 1–2天内=成立；3天–1周=边缘；**两周以上=直接pass**
  │     ├─ 涉及"某地出新规"？（查**规范本体哪一年立的**）→ 分清"新规范"还是"老规定新执法"
  │     └─ 时间戳是今天、权威源是今天 → ✓ 过
  │
  ├─【闸门3】议论够量、且量是真的吗？
  │     ├─ 讨论量个位数 → ✗ 写出来即造假
  │     ├─ 讨论量中等（数百）但真人议论密集、质量高 → ⚠ 可写但须向领导报薄
  │     ├─ 阅读量高、讨论量低（时政类常见）→ ⚠ 议论未形成，等
  │     └─ 讨论量上千且真人为主体 → ✓ 过
  │
  ├─【闸门4】议题性质匹配体裁吗？
  │     ├─ 中央重要指示/领导人讲话 → ✓ 反响型（**体例 2026-10-15 已定**：用 rmt-rb skill 的日报骨架，主体换成干部群众表态，不写报送方建议）
  │     ├─ 纯企业自主行为（定价、营销、公关）→ ✗ 缺"做法"这一半
  │     │     └─ **★例外：换落点能救回来★**——如"某茶饮品牌促销成本争议促销成本转嫁"→特许经营信息披露
  │     ├─ 纯个人行为、家庭伦理、司法个案 → ✗ 无区级接口或报送风险高
  │     ├─ 宏观数据（某地消费数据、人口、股市）→ ✗ 不是事件、落点空
  │     └─ 公共事务、有部门职责对应 → ✓ 过
  │
  ├─【闸门5】事实核到源头了吗？
  │     ├─ 关键事实只有网传视频/单方叙述/自媒体转述 → ✗ 事实不实即报送风险
  │     ├─ 口径打架（三个数不同版本）→ ⚠ 分类型：同口径取相对值／不同口径分别标注
  │     ├─ 由头本身是不实信息 → ⚠ 题目须写明"实为谣言/恶搞图"，不删
  │     └─ 有部门通报/央媒报道/原文文件 → ✓ 过
  │
  ├─【闸门6】落点有接口吗？（★接口检验★）
  │     ├─ 问一句：**领导拿到这条，能下令干什么？**
  │     ├─ 答不上来 → ✗ 落点空，结尾必是空话
  │     ├─ 答得上来但**决定权在上层**（如"降低社保基数"）→ ⚠ **落点搬家**：搬到本级的服务与落实环节（告知/辅导/帮扶/公示）
  │     ├─ 素材好但落点够不着 → ⚠ 先试换落点，换不出来就是没有
  │     └─ 明确指向区级某部门且可执行 → ✓ 过
  │
  └─【闸门7】★特别处置：要不要先问？★（2026-10-13 新增）
        ├─ 议论主体指向**本系统或本部门的效率／作风** → ⚠ 先问
        ├─ 涉及**在办案件、敏感企业、可能引发次生舆情**的题材 → ⚠ 先问
        ├─ 涉及**领导个人、人事、纪检**相关内容 → ⚠ 先问
        └─ 处置：标注"报前请领导先定要不要报"，**并列明撤下条件（不采认即撤，不改写成更弱的版本）**
```

> **为什么要有闸门 7**：某车型制动争议（敏感度最高）和某日用品化学物争议（议论指向部门效率）这两篇，**六道闸门全过，但都需要领导先拍板**。它们不是"不该写"，而是"写了要额外走一道程序"。**这类题材自行决定＝越位。**

## 二、七道闸门的判据与实例（照这个查）

| 闸门 | 判据 | 反例（史实） | 正例 |
|---|---|---|---|
| **1 议题真实** | ①除机构号外**有没有人在说自己的话**；②**我能不能引到真人原话**（来源表至少一条网民个人账号） | 平安中国指示（政务号刷屏）、春秋假（地方发布＋景区营销）、14岁女孩（矩阵号同文案）；**某低价商品仅退款争议／某上市公司食品安全处罚／校园电动车（话题页有真人，但稿中论据全来自媒体转述）** | 社保基数诉求（真人密集） |
| **2 时效窗口** | **原始发布日 ＋ 话题页最新帖日** | 某连锁药店旧闻新炒（4月旧闻）、长春零下20度（2020年）、**某养老陪伴服务议题（议论停在8—9月）** | 北京警方通报（10-12发、10-13热议） |
| **3 议论够量** | 讨论量＋**真人在不在** | 某商超打包费争议（讨论量4）、某区广场舞（留言板4条） | 单位欠缴社保（6205／2069.9万） |
| **4 性质匹配** | 是不是公共事务、有没有部门职责 | 某茶饮品牌促销成本争议营销（纯企业）、京东双11（企业）、某地消费数据（宏观数据） | 校园藏手机神器（市场监管＋教育） |
| **5 事实有源** | 部门通报／央媒／原文文件 | 某遛犬冲突（无警方通报）、细烟（源头找不到）、某生活方式提法争议（无一手） | 天眼核查（中科院官网）、郑凡案（警方立案） |
| **6 落点有接口** | **领导能下令干什么** | 某休假安排议题（国家节假日安排）、某体育赛事舆论（区里没有职业体育） | 某挂号系统被攻击（区卫健局可查号源管理） |
| **7 特别处置** | 指向本系统效率／在办案件／人事纪检 → **先问** | 某车型制动争议（敏感度最高）、某日用品化学物争议（议论指向部门效率） | — （这一类不自决，无正例） |

## 三、三类结果怎么处置

| 结果 | 条件 | 处置 |
|---|---|---|
| **✓ 写** | 六项全过 | 进入写稿流程 |
| **⚠ 待观察** | **只缺"量"或"时效窗口还差一点"**，其余五项成立 | **记下"该盯什么信号"**，列入候补；信号出现即写 |
| **✗ pass** | 缺任一项硬性（假热／旧闻／无源／性质不符／落点空） | **当场毙，不进写稿流程**；记入"被否掉的选题"表，**带数据＋否掉原因**（不是"热度不够"四个字） |

### ★"待观察"必须写清盯什么信号★（史实）

| 候补选题 | 盯的信号 | 结果 |
|---|---|---|
| 某境外疫情传闻 | 议论是否从"真假"转向"怎么防"、有无官方动作 | **信号出现 → 10-09 改判为写** |
| 急救车司机劳务派遣 | 讨论量是否涨 | **反向走（403440→48324），信号未出现** |
| 妙瓦底电诈园区招募 | 是否挖到个人号原话 | 未挖到，未写 |
| 劳务外包 | 讨论量是否破千、是否有官媒评论 | **10-13 等到人社部新规 → 依据齐了** |

## 四、可自动化 vs 必须人判（决定项目怎么设计）

**这棵树的价值不只在"给人看"，还在"哪些能代码化"。**

| 闸门 | 可自动化 | 说明 |
|---|---|---|
| 1 议题真实 | **半自动** | 机构号过滤（词表已有）、矩阵号识别（同文案相似度）、榜单词条型判定（链接带不带 `#`）**都能代码化**；**1-②"来源表里有没有网民个人账号"也可自动检**；"是不是博主解读"需人判 |
| 2 时效窗口 | **可自动** | 抓**帖子卡片**里的时间戳、权威源发布日期——**纯日期计算**（★不能用整页文本，会捞到侧栏时间★） |
| 3 议论够量 | **可自动** | 讨论量阈值判定（如 <10 直接毙）；**另加 3-② 发帖人构成**（见下） |
| 4 性质匹配 | **半自动** | 关键词打标（企业/宏观/司法/中央指示）可自动初筛；**体裁定性需人判** |
| 5 事实有源 | **半自动** | 来源表里有没有"部门通报/央媒/原文"可自动检；**"够不够权威"需人判** |
| 6 落点有接口 | **人判为主** | 需**区级部门职责图谱**；可做成"议题类型→责任部门"的映射表辅助 |
| 7 特别处置 | **人判（且必须由领导定）** | 无法自动化——**"要不要报"本身是政治判断** |

**★闸门 3-②（2026-10-13 新增）：议论的"主体"是不是网民★**

帖子新鲜**不等于**网民在议论。判据：24h 新帖中**普通用户（含月费会员）≥30%**，
**且达人/机构（蓝V＋黄V）<50%**；两条线任一不过即降级。新帖 <5 条不下结论。

> **已知局限**：微博活跃用户大多带会员标识，**分不开"买月费会员的博主"与"普通网民"**
> （实测"某社保税务处罚口径"的财经博主全被算成普通用户）。**所以"普通用户占比"只能当上界看**，
> 可靠识别的是"机构+黄V 明确主导"这一种；**"无认证的博主主导"仍须人判**。

> **★设计结论★：闸门 2、3 能全自动（成本最低、收益最高，优先做）；1、4、5 半自动（机器初筛＋人复核）；6、7 人判（6 可用映射表提速，7 必须领导定）。**
> **这也回答了"为什么不能全自动"——第六道闸门问的是"领导能下令干什么"，第七道问的是"要不要报"，这两个都是政治判断，不能交给模型。**

## 五、这张表怎么用（三处）

1. **写稿前**：候选选题逐个过七个闸门，**先毙后写**（我这几天的错都是"先写后毙"）；
2. **复盘时**：被否的选题对照填写"卡在哪一闸门"，**看哪一闸门反复卡**；
3. **做评测**：闸门 1–5 的判据可写成规则，**用 52 篇历史稿验证规则准不准**——这是 `eval/` 的核心测试。

> **★第三条已经做过一次（2026-10-13）★**：用 52 篇历史稿反向检验，**原版六道闸门只拦得住 16 个历史问题里的 11 个（69%）**；补上判据 1-② 与闸门 7 后，**16 个全部拦得住（100%）**。过程与明细见《docs/02-验证-反向验证.md》。
>
> **这套动作的价值：规则 → 用真实数据验证 → 发现漏洞 → 修订 → 再验证。** 这是本方法论区别于"凭经验写稿"的地方——**标准本身是可检验、可迭代的**。

## 六、与 skill 的关系（避免重复）

| 文件 | 管什么 |
|---|---|
| 分支 skill（`rmt-yq` 单篇 ／ `rmt-rb` 日报） | **写作体例**（题目/开头/主体/结尾怎么写）＋排版规格＋交付自检 |
| `工作手册（私有，未随包发布）` | **操作流程**（怎么抓数、怎么核、数据源分工）＋踩坑记录＋成品台账 |
| **本文件** | **选题判定**（哪条值得写）——**写作之前的那一关** |

**三者的关系：本文件决定"写不写"，分支 skill 决定"怎么写"，手册决定"怎么做到"。**
