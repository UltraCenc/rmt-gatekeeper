# 稿件库：怎么建、怎么更新（机制说明）

> 配套：`docs/01`—`docs/07`。**本文只讲机制，不含任何真实选题与稿件内容。**
> 起因：这是一个每天都在产出的写稿流程，稿件只会越攒越多。真正的问题是——**攒下来的东西，怎么才能被用上？**

---

## 一、先分清"存"和"用"

| 做法 | 结果 |
|---|---|
| 把全部稿件存成一个合集 | **读不完**。全文语料一次就是几十万字；而写稿时真正需要的是"同类怎么写、同类错在哪"，不是重读全文 |
| 只存不索引 | 等于没存——下次动笔还得从零判断，攒的量再大也不产生复利 |
| **索引化 ＋ 按议题族分组** | 每次动笔前能真的读进去 → 才可能"越写越准" |

> **核心判断：能被读进去的才叫资源，读不进去的只是硬盘占用。**

**一条容易混淆的边界**：这套机制**不是训练**。它不改变任何模型的权重，起作用的路径是——
**库 → 动笔前被读进去 → 判据被修订 → 断言把修订守住**。库是原料，能力长在判据和断言上。

---

## 二、两区怎么分（口径只有一条）

| 项 | 说明 |
|---|---|
| **分区判据** | **内容硬性项**是否全过：①落点可执行（拿到这条能下令干什么）②主体是相关人群自己的声音 ③关键事实核到源头 |
| 过 → **参考区** | 可仿结构：开头怎么交代来历、第二段为什么最长、结尾三层怎么落 |
| 不过 → **反例区** | 必须写清"卡在哪"——落点空 / 主体不是当事人群 / 事实无源 / 时效不过 |
| **归类规则** | **一篇只归一档，按最严重的那一项定** |

**为什么格式类检查不进分区**：它可被脚本自动核，且一旦收敛就不再是瓶颈——放进分区只会让"合格"这个标签失焦。做法是把它降为一行附注（"须注意：缺 N 项格式"）。

---

## 三、议题族索引（这才是入口）

- **为什么按议题族、不按日期或体裁**：动笔时的问题是"**这类稿怎么写**"，不是"上个月写了什么"。
- **每族三样东西**：可仿的样本 ／ 该避的坑 ／ **该族纪律**。
- **"该族纪律"是这套索引最值钱的一列**：它是这一族**反复踩出来的具体约束**（比总则更具体、更可执行）。总则说"落点要有接口"，族纪律说的是"这一族的决定权在上层，落点必须搬到告知／辅导／帮扶环节"。

**族的划分标准（两条同时满足）**：①指向同一个责任部门（或同一组部门）②面对同一类舆论诉求。
例如：社会保障与劳动权益／滥用售后与投诉规则／食品与消费安全／网络内容治理与 AI／医疗与医患／养老与老龄／教育与未成年人／婚俗与家庭／公共安全与地方治理／跨境电诈与反诈／企业行为的落点搬家。

**族的数量不设指标**：新议题出现、且旧族装不下时才新建——避免族名膨胀到互相重叠。

## 四、一篇新稿怎么进库（收尾自动追加）

| 步 | 动作 | 谁做 |
|---|---|---|
| 1 | 正文字数实测 | 脚本 |
| 2 | 格式硬性项自检（十余项） | 脚本 |
| 3 | "来源里有没有可引用的当事人声音"机械核 | 脚本 |
| 4 | **定档（参考区／反例区）＋写"可复用之处"或"卡在哪"** | 人判 |
| 5 | 档位若变动，写一句原因（留痕） | 人判 |

> **纪律：登记动作与"成品登记"并列写进收尾清单。**
> 不写进清单的事，等于不会发生——这是这套流程里最容易失效的一环。

---

## 五、三条维护纪律（都由失效模式反推）

| # | 纪律 | 违反了会怎样 |
|---|---|---|
| 1 | **库必须短**：只放索引与结论，不放全文 | 一旦堆成合集，就再没人读 → 库废 |
| 2 | **库必须被读**：写稿流程的第一步就是查议题族 | 只登记不读 → 库退化成台账 |
| 3 | **口径必须单一**：分区只看内容硬性项 | 多套口径并存 → 同一篇在两处档位不同 → 库失去可信度 |

---

## 六、与"评测集"的分工（别混用）

| | 稿件库 | 评测集 |
|---|---|---|
| 用途 | **写稿参考**（给人／给写稿环节读） | **规则回归**（给判定工具读） |
| 用法 | 动笔前查同族样本与坑 | 跑规则，看拦不拦得住 |
| 样本取向 | 全部稿件都收（含反例） | 只收**判决明确**的：参考区的合格样本作正样本；反例区**原因明确**的作反样本 |
| 中间那一档 | 收（标注"须注意"） | **不进评测集**——它们是"格式已达标、内容仍有洞"的人判训练样本，不是自动判据的靶子 |

> 同一批标注可以派两个用场，但**用途不同、不能互相替代**：库回答"怎么写"，评测集回答"规则准不准"。
