## 一、判定器做什么

输入一个话题标签，自动输出**可直接决策的结论**：

```
【某社保欠缴处罚新规】
  事情时效 新（央视等 10-12 报道）
  议论时效 新（最新帖 0 天前｜今天12:12 / 今天11:56 / 今天11:17）
  议论量　 够量（6516 讨论／2498.4万 阅读，取自 话题库）
  → 可写　（时效成立、议论够量）
```

---

## 二、★核心设计：时效是两个独立检查★

**这是做工具过程中逼出来的最重要的认识。** 原来标准里只有一条"时效"，实测发现必须拆成两条：

| 检查 | 看什么 | 判据 |
|---|---|---|
| **事情时效** | 权威源**原始发布日** | ≤2天 新｜3–14天 边缘｜>14天 旧 |
| **议论时效** | 话题页**最新帖日期** | 同上 |

**为什么必须拆——组合起来才看得出性质：**

| 事情 | 议论 | 性质 | 处置 |
|---|---|---|---|
| 旧 | 旧 | **旧闻新炒**（某连锁药店旧闻新炒：事情 4月、议论 22天前） | **pass** |
| 新 | 旧 | **网民没反应**（某养老陪伴服务议题：媒体 10-13 报道、议论 33天前） | **pass** |
| **旧** | **新** | **旧案翻红**——议论是新的 | **可写**（常见好选题，勿误杀） |
| 新 | 新 | 时效成立 | 看议论量 |

> **★如果不拆这两条，就会犯两种相反的错误★**：把"旧案翻红"误杀（损失好选题），或者把"媒体报了但网民没反应"当成热舆情（白写稿，某养老陪伴服务议题就是这样）。

## 三、闸门 3：议论量三级

| 讨论量 | 判定 |
|---|---|
| <10 | ✗ 个位数，写出来即失真 |
| 10–999 | ⚠ 偏薄，可写但报告须注明 |
| ≥1000 | ✓ 够量 |

---

## 四、最终结论规则（闸门 2 × 闸门 3 合成）

```
事情旧 ＋ 议论旧  → pass（旧闻新炒）
事情新 ＋ 议论旧  → pass（网民没反应）
事情旧 ＋ 议论新  → 可写（旧案翻红）
讨论量 个位数     → pass（写出来即失真）
讨论量 偏薄       → 可写（报告须注明议论偏薄）
讨论量 够量       → 可写
```

## 五、实现要点（踩过的坑都在这里）

| 环节 | 做法／坑 |
|---|---|
| **双入口取数** | **两个入口都要走**：话题库 `s.weibo.com/topic?q=` ＋ 搜索页。**一个入口拿不到不代表没有**（`#某养老陪伴服务议题#` 只有话题库有数据） |
| **★字段错位坑★** | **两个入口的文本格式不同，正则必须分别对齐**：<br>· 话题库：`830讨论 1405.1万阅读`（讨论在前）<br>· 搜索页：`阅读量1405.1万 讨论量830`（**阅读在前**）<br>**v2 就栽在这**——搜索页的数据被当成"讨论量"读走，出现"325.4万讨论／658阅读"这种明显错位的输出 |
| **时间戳解析** | 支持五种：`N秒/分钟前`、`今天 HH:MM`、`昨天 HH:MM`、`N天前`、`MM月DD日 HH:MM`、`YYYY年MM月DD日` |
| **跨年修正** | "01月21日"在 10 月读到，须判为**上一年**（天数差为负且绝对值大时回退一年） |
| **议事时效取值** | 取时间戳列表的**最小值**（最新一条），不是平均值 |
| **事情时效来源** | 暂由人工提供（权威源原始发布日）；**未自动化**——见"待办" |

## 六之二、★v4 新增：榜单词条型的替代判据★

**为什么加**：v3 只会看"讨论量"，**取不到就输出"待补数据"**——这会让人误以为"没数据＝不能写"。但 10-13 下午的 **"某部委参保扩面动作"（社会榜第 1、热度 229 万、一分钟内十几条新帖）恰恰是真热点，该写**。

**"抓不到数据"与"议论没形成"是两回事。**

**适用**：榜单链接**不带 `#`**、或话题库返回"未找到"的词条——**没有讨论量／阅读量可读**。

**改用三个替代指标：**

| 指标 | 判据 | 怎么取 |
|---|---|---|
| **榜单热度值** | ≥100 万 | 直接从榜单读 |
| **在榜位次** | 前 10 | 直接从榜单读 |
| **帖子密度** | 抽样帖中 **24 小时内新帖占比 ≥30%** | 搜索页抓 15 条，解析时间戳 |

**判定规则**：≥2 项命中**且帖子密度通过** → **议论充分（榜单词条型）**，可写，**稿中用"热度值"标注、不写讨论量**；≥2 项命中但密度不通过 → 议论偏薄；其余 → 议论不足。

**v4 验证（4 条，含正反例）：**

| 词条 | 热度 | 位次 | 新鲜帖占比 | 判定 | 对不对 |
|---|---|---|---|---|---|
| **某部委参保扩面动作** | **229万 ✓** | **第1 ✓** | **93% ✓** | **议论充分** | ✅ 真热点 |
| **某茶饮品牌促销成本争议** | 56.5万 ✗ | **第9 ✓** | **93% ✓** | **议论充分** | ✅ 今天新出词条 |
| 某养老陪伴服务议题 | 不在榜 ✗ | 不在榜 ✗ | 36% | **议论不足** | ✅ 确实不该写 |
| 某社保税务处罚口径 | 41.2万 ✗ | 第12 ✗ | 100% ✓ | 议论不足 | ✅（另按"主体是博主解读"否决） |

**★遗留盲区（尚未补）★**：帖子密度**只看时间，不看是谁发的**。"某社保税务处罚口径"新鲜帖占比 100%，**但发帖主体是财经博主解读**——这一层仍须人判。**下一步可加"发帖人构成抽样"（机构号／黄V／普通用户的占比）。**
